# Support the current baseline major without runtime expiry

Maintaining multiple baseline major versions would add support work, while a live expiry policy would change the behavior of pinned application pipelines without an upgrade. Maintain only the current baseline major and deliver fixes through owner-reviewed Dependabot upgrade pull requests, prioritizing critical fixes. V1 has no runtime minimum-version or expiry gate, accepting delayed adoption in exchange for explicit upgrades and reproducible pinned behavior.
